Cost Assumptions & Modeling Principles

Pricing Source

Standard Public On-Demand Rates

$0.04048 / vCPU-hr · $0.004445 / GB-hr (c6g / m6g compute baseline)

Region & Baseline

AWS us-east-1 (N. Virginia)

Single reference standard currency USD normalized across multi-cluster fleet

Calculation Period

30-Day Rolling Window

Normalized to 730 runtime hours per monthly cycle, accounting for autoscaling variance

Allocation Method

Pod Capacity Requests

Committed resource reservations (`resources.requests`) amortized across actual worker capacity.

Included Resources

CPU, Memory & Multi-AZ Replicas

Direct core requests, heap/RAM limits, and scheduled replica count footprints.

Excluded Charges

Storage & Network Egress

Excludes EBS persistent volumes, inter-AZ transit data fees, and $0.10/hr EKS control plane.

info

Notice: Telemetry Right-Sizing Model Only

These financial metrics reflect heuristic capacity models calculated strictly from container resource requests and telemetry utilization baselines to help engineering teams prioritize right-sizing workflows. They do not mirror exact cloud provider invoices, reserved instance blended amortizations, enterprise discount programs (EDP), or savings plans contracts.
